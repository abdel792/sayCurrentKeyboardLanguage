# sayCurrentKeyboardLanguage

* Автор(ы): Abdel, Noelia.

# Презентация #

Этот аддон был создан по запросу одного из участников списка рассылки nvda-addons.

Он предоставляет скрипт без назначенного жеста, который позволяет получить и озвучить язык текущей раскладки клавиатуры.

При двойном нажатии выводит язык системы по умолчанию.

В первой версии этого модуля он предлагался как простой globalPlugin для вставки в каталог конфигурации NVDA, затем он был преобразован в аддон.

## Примечания ##

Чтобы назначить жест для скрипта, выводящего язык клавиатуры, выполните следующие действия:

* Откройте меню NVDA с помощью комбинации "NVDA + N";
* Перейдите в меню настроек NVDA;
* Затем перейдите в подменю "Жесты ввода".
* Затем выберите категория "Ввод" и откройте её стрелкой вправо.
* Перейдите к пункту с надписью "Сообщает язык используемой клавиатуры, при двойном нажатии выдает язык системы по умолчанию";
* После этого нажмите Alt + A, чтобы добавить жест, и введите "NVDA + F4" или другой жест по вашему выбору;
* Как только это будет сделано, нажмите стрелку вверх один раз, вы услышите "выбранный вами жест, все раскладки";
* Подтвердите нажатием Enter, затем перейдите по Tab к кнопке OK и нажмите Enter;
* Выбранный вами жест теперь должен вызывать скрипт, сообщающий язык клавиатуры.
