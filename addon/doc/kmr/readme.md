# Zimanê KlavyeyaNiha

* Nivîskar(an): Abdel, Noelia.

# Pêşkêşkirin #

Ev pêvek piştî daxwazek ji endamek di lîsteya nameyê ya nvda-addons de hate afirandin.

Ew skrîptek bê jest peyda dike, ku destûrê dide wergirtin û dayîna zimanê klavyeya heyî.

Ger du caran were pêlkirin, zimanê xwerû yê sîstemê dide.

Di guhertoya yekem a vê modulê de, ew wekî globalPlugin-ek hêsan hatibû pêşniyar kirin ku di peldanka mîhengê ya NVDA-yê de were danîn, dûv re ew veguherî pêvekekê.

## Têbînî ##

Ji bo danîna jestek li ser skrîptê ku zimanê klavyeyê dide, van gavan bişopînin:

* Menûya NVDA-yê bi "NVDA + N" veke;
* Biçe menûya tercîhên NVDAyê;
* Dûv re biçin binmenuyê "Jestên têketinê".
* Dûv re kategoriya "Input" hilbijêrin, û bi tîra rastê vekin.
* Biçe ser tiştê bi navê "Zimanê klavyeya ku tê bikaranîn dide, ger du caran were pêlkirin, zimanê xwerû yê pergalê dide";
* Piştî ku qediya, ji bo lêzêdekirina jestek Alt + A bikirtînin, û "NVDA + F4" an jî jestek din a bijartina xwe binivîsin;
* Ev qediya, carekê tîra jorîn bikirtînin, hûn ê "jesta weya bijartî, hemî sêwiran" bibihîzin;
* Bi Enterê verast bike, dû re bişkoja Tabê bikirtîne da ku OK be, paşê Enterê bikirtîne;
* Tevgera ku te hilbijartiye divê hingê skrîptê ku zimanê klavyeyê dide gazî bike.
